# Kitchen Timer in C++ with Arduino ⏱️🧑‍🍳

Простий та надійний кухонний таймер, створений на базі мікроконтролера Arduino з використанням мови програмування C++. Проект оптимізовано для мінімалістичного керування за допомогою **всього однієї кнопки** та звукового сповіщення через **пищалку (зумер)**.

## ✨ Особливості (Features)
* **Керування однією кнопкою**: встановлення часу, запуск, пауза та скидання виконуються однією кнопкою (завдяки розпізнаванню коротких та довгих натискань).
* **Звукове сповіщення**: гучний переривчастий сигнал пищалки після завершення відліку.
* **Енергоощадність**: чистий C++ код без зайвих затримок (`delay()`), що забезпечує точність відліку часу.

## 🛠️ Компоненти (Hardware Required)
Для збірки проекту вам знадобляться:
1. **Плата Arduino** (Uno, Nano або Pro Mini).
2. **ТАКТ-кнопка** (Button) — 1 шт.
3. **П’єзо-пищалка (Buzzer)** — активна або пасивна — 1 шт.
4. **Дисплей** (наприклад, LCD 16x2 з I2C або 4-розрядний індикатор TM1637) — *вкажіть ваш тип дисплея*.
5. Резистор на 10 кОм (якщо кнопка підключається без внутрішнього `INPUT_PULLUP`).
6. Макетна плата та дроти.

## 🔌 Схема підключення (Wiring Diagram)

| Компонент | Пін Arduino | Примітка |
| :--- | :--- | :--- |
| **Кнопка (Button)** | **D2** | Підтримує зовнішні переривання (рекомендовано) |
| **Пищалка (Buzzer +)** | **D8** | Цифровий вихід для звуку |
| **Дисплей (SDA)** | **A4** | Для I2C інтерфейсу |
| **Дисплей (SCL)** | **A5** | Для I2C інтерфейсу |
| **GND / VCC** | GND / 5V | Живлення компонентів |

## 🎮 Як користуватися (Usage)

Керування всіма функціями таймера реалізовано через комбінацію натискань однієї кнопки:

1. **Встановлення часу (Режим налаштування):**
   * **Коротке натискання:** додає +1 хвилину до таймера (або +30 секунд, залежно від вашої прошивки).
   * **Довге натискання (утримування ~2 сек):** фіксує час та запускає зворотний відлік.
2. **Під час зворотного відліку:**
   * **Коротке натискання:** ставить таймер на **паузу**. Наступне коротке натискання — відновлює відлік.
   * **Довге натискання:** повністю скасовує відлік та скидає час на нуль.
3. **Після завершення часу (Звучить сигнал):**
   * **Будь-яке натискання:** вимикає пищалку та повертає таймер у режим очікування.

## 🚀 Початок роботи (Getting Started)

### Налаштування середовища
1. Встановіть [Arduino IDE](https://arduino.cc).
2. Якщо використовуєте бібліотеки для дисплея (наприклад, `LiquidCrystal_I2C`), встановіть їх через *Скетч -> Включити бібліотеку -> Керувати бібліотеками*.

### Встановлення
1. Склонуйте цей репозиторій:
   ```bash
   git clone https://github.com
   ```
2. Відкрийте файл `.ino` в Arduino IDE.
3. Підключіть Arduino до ПК, оберіть правильний COM-порт та тип плати.
4. Натисніть кнопку **Upload (Завантажити)**.
